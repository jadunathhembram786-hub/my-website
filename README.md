# 🌿 Botany Notes — B.Sc. Botany Digital Notebook

> **Learn Plants. Understand Life. 🌱**

A clean, interactive and student-friendly digital notebook designed for **B.Sc. Botany students**.

This website brings together Botany notes, important questions, MCQs, bookmarks, topic searching and study progress in one place.

---

## 📚 About the Project

**Botany Notes** is a digital study platform created to make B.Sc. Botany revision easier and more organized.

Instead of keeping notes, questions and revision material scattered across different notebooks and files, this project combines them into a single interactive web page.

The website uses a handwritten-notebook-inspired design with blue botanical headings, clean white pages and responsive layouts.
